# Alim Khan Mazlish (Sayem) — Portfolio

Senior Graphic Designer, TallyKhata. One-page portfolio built with vanilla HTML/CSS/JS.

## Sections
Home · About · SureCash · TallyKhata · TallyPay · Juddho71 · Video · Contact

## Tech
- HTML5, CSS3, vanilla JavaScript
- [AOS](https://michalsnik.github.io/aos/) — scroll animations
- [GLightbox](https://biati-digital.github.io/glightbox/) — image gallery lightbox
- YouTube embeds (click-to-play, stays on-site)

## Run locally
Open `index.html` directly, or serve the folder with any static file server, e.g.:

```bash
powershell -File server.ps1
```

Then visit http://localhost:8080

## Deploy to GitHub Pages
1. Push this folder's contents to a GitHub repository (e.g. `username.github.io` for a root site, or any repo name for a project site).
2. In the repo settings → **Pages**, set the source to the `main` branch, root folder.
3. The site will be published at `https://<username>.github.io/<repo-name>/`.
